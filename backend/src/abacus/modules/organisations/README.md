# organisations

Clients and client entities (glossary). Owns `clients` and `client_entities` (ADR-103).

## Public interface (`api.py`)
- `create_client(tx, tenant_id, client_name, client_entity_name) -> NewClient` runs inside the caller's unit of work and records `client.created` and `client_entity.created`. The caller authorises the action that needs it (for now `engagement.create`; client management routes come later).
- `client_names(session, entity_ids)` returns the client and entity names for engagements the caller has already authorised.

## Clients you already have (SPEC-025 AC-1; TASK-043)
- **Normalised names:** `clients.normalised_name` and `client_entities.normalised_name` are generated by the database: lower case, punctuation as spaces, legal suffixes (Inc, LLC, Ltd, Corp and others) dropped, spaces collapsed. `normalise()` mirrors it, kept in step by a unit test.
- **One name per client:** an entity name is unique per client (409 `entity_exists`).
- **Search:** `find_clients` matches by normalised prefix (or exactly, for duplicate checks).
- **Existing clients:** `client_with_entity` uses an existing client with an existing or new entity.
