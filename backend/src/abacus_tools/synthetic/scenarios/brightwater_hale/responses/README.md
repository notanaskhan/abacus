# Recorded fake-model responses (F-04-T19; F-04.26)

One JSON file per response, read by `responses.install(fake)`:

```json
{"prompt_ref": "evidence.screen@v0", "content_sha256": "<64 hex>", "response": {"action": "..."}}
```

- `content_sha256` is the SHA-256 of a scenario document that the prompt input names, or of the rendered input itself.
- `response` is the model's JSON output, or a string.
- These are scenario data, written by hand from the scenario documents and never generated by a model.
- Each cited value must resolve to a fixed page region that code verifies.
- F-04-T25 adds the files, together with the scenario documents whose hashes key them (its row: "Scenario documents with fixed citation regions and fake-model response data"). The E0 audit-core slice (F-04-T20) loads no documents, so it has none. The planted unsupported value is what makes SHL-10c and SHL-09e show "Uncited".
