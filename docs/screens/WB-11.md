## Notes

The drawer is `role=dialog` with `aria-modal`; focus moves to ✕ and returns to the invoking control; Escape closes only the top layer. The timeline is an `ol` with `time datetime`. Write rows join `write-capabilities.yaml`: enabled shows Check, declared-but-off shows Lock and "Off for this firm", unregistered is dropped. Event and client labels resolve at read time through `visible()`; walled clients and their counts never appear.
