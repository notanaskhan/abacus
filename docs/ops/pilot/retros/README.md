# Pilot 0 retros and PW1 success metrics (F-09-T126; F-09 J2; Q-04 AC-7)

Before PW1 opens (Tue Jun 1, 2027), AY holds a retro with each Pilot 0 partner and agrees the PW1
success metrics with each firm's champion. Acceptance: each partner's retro note and signed-off
success metrics are filed by Fri May 28, 2027.

**Where things live.** The retro note itself (what the partner said, in their words) and the
champion's written sign-off go in the vault: they can name people and firms. This folder holds the
index, by pilot code, with dates and vault references, and the metrics each firm agreed, which are
the platform's own signals (`docs/product/discovery/thresholds.md`), never a firm's private numbers.

## Retro note (the vault document's sections)
1. Sessions walked (dates; journeys: J02, J12, J04-PBC, the tax slice) and who took part (roles).
2. What worked, in the partner's words.
3. What did not: each linked to its row in the top-10 log (`docs/ops/pilot/pilot-0-usability-log.md`)
   or its issue; anything new is filed the same way (S1–S3).
4. Requests for new capability: each goes to the triage log (F-09-T128), never promised in the retro.
5. PW1 readiness: engagements the firm will bring (1–3 per audit partner; EBP plans with Oct-15
   filings, June-30 year-ends), its people for onboarding, any blocker.
6. The success metrics below, agreed.
