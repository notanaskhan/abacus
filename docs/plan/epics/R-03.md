### 2.2 In scope

1. **Capture service (red `evidence`):** capture sessions in the caller's grant scope; page upload with server-side EXIF transpose and strip, quality flags (glare, blur, low resolution) computed by code, retake, delete, reorder; deterministic stitching to one PDF; routing to a request item or to the firm Inbox; staging erase.
2. **Phone hand-off (red `identity`):** link purpose `capture_handoff` on A-08's framework; QR module matrix from the server; single exchange to a 10-minute credential bound to one capture session; "Email me a link" to the session owner's own address; disconnect; kill switch.
3. **Prospect intake (amber `engagements`, red `identity` and `evidence`):** firm-imported JSON templates; link purpose `intake` with email code; autosaved, server-validated steps; deterministic helper; document slots with defer and withdraw in a pre-engagement store; submit with lock; conflict re-run, notification and acceptance-record activity; decline and acceptance consumers; G3 revokes the link.
4. **Tax payments (amber `notices`, `portal`):** prepared by code from the notice record, shared by a person, read in POR-10 with derived Overdue in the client's time zone, confirmation upload filed to the notice with the confirmation number kept as last 4; `agency_payment_channels` reference set; invoices read through I-04's contract when it exists.
5. **Three screens** with fixtures, scenarios, 390 layouts, parity, axe, and the post-window seams.

## 6. Accrued Agent
