# K-04 · Board, triggers, review package & set up with AI

> Epic specification and task backlog, written Saturday 2026-10-17 for Sprint 0 starting Monday 2026-10-19. Task references `Tnn` in the text mean `K-04-Tnn`. Chapter 01 is the plan of record for dates, owners and scope. Chapter 09 is the register of record for `DEC-nn`, `DF-nn` and `P-nn` IDs; repo ADR numbers are F-02's reservations. **N** = notanaskhan, **AY** = ayushkbhatia. The CSV twin of §9 is `sections/epics/K-04.tasks.csv`.
>
> **Short version.** K-04 turns the engine K-03 builds (templates v2, Sheets, agent columns) into everyday audit work. It ships six screens and one contract:
> 1. **ENG-10 Board** and the **C14 Board and program-status read model**. The Board is a view over program, control and close statuses that already exist. A drop can start an agent; it never signs anything. A drop onto a sign-off column opens SHL-12.
> 2. **ENG-11 Engagement settings** with **engagement triggers** (`EngagementAgent` policy P-8 under ADR P-51, written **EA-P8** throughout this spec so it is never read as chapter 09's dormant ADR P-08). Triggers only propose or draft, have a per-engagement kill switch, and reject duplicates.
> 3. **ENG-12 Engagement dashboard**: Reviewer, Preparer and Client lenses; milestones with a code-computed health rule.
> 4. **SHL-19 Agent review package**: set-level review of agent results, exception dispositions, corrections that survive a rerun, then sign-off through SHL-12 and a deterministic export.
> 5. **SHL-21 Link requests**: one piece of evidence fulfils requests in several engagements of the same client, by reference and never by copy, with walls that hide whole engagements and show no count.
> 6. **ENG-14 Set up with AI**: the `engagements.setup_planner` capability reads last year's files, proposes a cited five-step plan, asks only what it cannot know, and creates nothing until a Manager or above confirms.
>
> **The epic runs inside the busy-season window.** S59–S65 (Jan 22 – Apr 27, 2029) overlaps the Jan 1 – Apr 20, 2029 window of every live firm (chapter 01 §1.2.4). Everything merges dark behind default-off flags. The five edits that touch live-path code are written and approved earlier but **ride the first post-window train, Tue Apr 24, 2029** (§4.9). That leaves three working days before M22 (Fri Apr 27, 2029), which is the epic's main schedule risk (§11, R1).
