> Epic specification and task backlog. Chapter 01 is the plan of record for dates, owners and scope. >
> **Short version.** The repo already has the AI governance layer: `ai_gateway.call()` with budgets, admission, the data boundary, the prompt registry and route parity, plus four `single_call` specialists. It has no agent runtime. P-10 builds that runtime **as an additive path** beside the live `call()` path, which the screener, upload reviewer and matcher keep using untouched:
> 1. **Gateway conversations:** `ai_gateway.converse()` with tool use and a structured final turn, under every `call()` invariant. There is no token streaming to browsers.
> 2. **Specs v2, the tool registry (C17) and the loop harness:** capability shapes, narrow typed tools of four kinds (`read`, `compute`, `propose`, `approved_write`), and a hand-rolled loop with hard limits.
> 3. **The run model:** 14 canonical run states, steps, plans, questions, decisions through P-04's decision cards, proposals through P-04's change sets, and writes only under P-04's approval grants. Runs and the engagement run workflow (`engagements.run`) execute on Temporal.
> 4. **Real time:** SSE run, session and badge streams plus the platform invalidation stream `GET /v1/events`, with polling as the permanent fallback (C6 v2).
> 5. **Records and metering:** durable, decision-relevant run records (trace v2, 7-year retention, hash chain, archive hook) and the agent-minute ledger.
>
> P-10 has **no catalogue screens**. Its surfaces are owned by P-09 (dock and trace), W-02 (Workbench), I-02 (Today), T-04 (TAX-08), A-01 (AUD-02) and others. It sits almost entirely inside the **Jan 1 – Apr 20, 2028 freeze window**: every schema and every live-path edit lands by **Fri Dec 24, 2027** (target Fri Dec 10, M15), and everything after that is new files merged dark behind default-off flags.

### 3.1 Gateway conversations (`converse()`)

*As notanaskhan, I want multi-turn tool use under exactly the governance `call()` has, so that every agent step stays budgeted, admitted, boundary-checked and attributed.*

- **AC-G1 (§7216, DE-4).** *Given* a ConverseCall whose `data_subjects` include the Stein taxpayer (consent declined), *when* `converse()` runs, *then* it refuses with `consent_7216` before any provider call, audits the refusal, and never reroutes (ADR-115).
