### 4.7 State machines after C-02

- **Proposed entry (C8 v2):** `proposed → within_threshold | review_required → approved → posted` · `approved → failed_post → posted` (retry) · `posted → reversed` (a reversing entry posts) · `approved → recorded_externally` (export path; attest after `client_approved`) · `review_required → client_approved → recorded_externally` (attest) · `→ rejected` · `→ client_declined` (A-06) · `approved → (approval_withdrawn) → within_threshold | review_required`.
- **Posting batch:** `proposed → posting → posted | failed_post`; `failed_post → posted` when every failed entry has been retried; "n failures resolved" is derived.
- **Close (C-01's enum; C-02 drives the last three):** `in_review → approved` (reviewer sign-off on the package, inside release) `→ delivered` (release) `→ locked` (after client approval); `locked → in_review` (reopen with reason).
- **Deliverable:** `drafting → draft → released → approved_by_client`; a regenerate creates a new draft version; a release is blocked by unmet preconditions (computed, not stored).
- **Tax hand-off:** `not_available` (derived) `→ ready` (derived: December and Locked) `→ handed_off → superseded`.
- **Ledger connection (W-01/A-02 words):** Connected · Needs attention · Needs reauth · Disconnected; posting allowed only when Connected.
- **W-9:** On file · Requested ‹date› · TIN mismatch; **backup withholding:** watch → started; **e-file record:** Not started → Filed · IRIS → Accepted | Rejected (manual records only).
