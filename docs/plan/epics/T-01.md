## 3. Features & user stories

### 3.1 Capturing §7216 consents, one purpose per document

**Story 1.1.** As Grace Holloway, I request the standard individual set for a household, and each purpose is its own signed document.
- *Given* the Feld household (filing unit `household_mfj` with spouse relationships), *when* Grace chooses "Use · AI disclosure (2 consents)" for TY2025, *then* `POST /v1/consents/requests` creates one consent set and **two** consents (`use`, `ai_disclosure`), renders two documents from the published templates "BH §7216 Consent to Use v2" and "BH §7216 Consent to Disclose — AI sub-processors v2", and drafts one C7 envelope with both documents and both spouses as required signers. Sending stays a human action in SIG-02 (`envelope.send`, N-02). Agent and system principals are refused at the matrix, live-human and database layers (INV-1, I-AGENT-NEVER).
- *Given* any template, *when* it renders, *then* the recipient block comes from the provider-terms register ("Amazon Web Services (Bedrock) · model inference · US") with its `provider_terms_version` stored on the consent, and a template whose fixed text names "Anthropic" as a recipient is refused at import (DF-16, conflict C-03).
- *Given* a single request with two purposes in one document, *then* the API refuses it (422 `one_purpose_per_document`); the table CHECK makes it unrepresentable (Rev. Proc. 2013-14 §5.05).

**Story 1.2 (signing and partial signing).**
- *Given* the C7 event `envelope.signer_signed` for Morgan Ferris only, *then* both Ferris consents stay `requested` with the display "Requested · 1 of 2 signed" (ADM-05a, CLI-05f), the agent gate stays closed, and the envelope's due date shows as "Envelope due Sep 23".

**Story 1.3 (record mode).** As Grace, I record consents the firm already collected through its own provider.
- *Given* a signed PDF and the signers' names and dates, *when* `POST /v1/consents/records` runs with fresh MFA, *then* the PDF is stored as evidence in COMPLIANCE-mode storage at the counsel-set floor, the consent is `signed` with `source = 'record'`, and the audit line reads "Consent recorded by Grace Holloway" (INV-5).
