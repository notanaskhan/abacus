## 1. Goal and user-visible outcome

**Goal.** Replace the repo's "Atelier" look (SPEC-016 direction C: Source Sans 3, Newsreader, accent `#7a4e12`, bordered cards, left icon rail) with the Accrued design system in one cut, and give every MVP-1 screen a merged template, kit and specimen to compose from, so that screen work becomes composition plus data. Concretely: tokens on a Tailwind v4 `@theme static`, self-hosted Geist, Geist Mono, Arimo and Gelasio, the AA-adjusted ink ladder, `format.ts` with exact decimals, a generated status vocabulary, one icon registry, L1 primitives, the O1–O6 overlay grammar with toasts and Undo, the DataTable grammars, the SourceViewer shell, MatchProvider, the ten MVP layout templates and ten specimens in an in-app `/components` gallery with tiered Playwright parity and axe, and the 51 Atelier screens re-skinned and moved behind the new shell until their replacements land.

## 3. Features & user stories

Invariants referenced: **INV-1** the agent never decides; **INV-2** citations shown are verified; **INV-3** walls hold; **INV-4** portal scopes are isolated; **INV-5** attribution is correct (chapter 01 §1.2).

### A. Foundations: tokens, fonts, the AA ladder, lint (S0)

**A1. As AY, I want one token source so that no screen can drift from the Accrued palette.**
- *Given* `packages/ui/src/tokens/tokens.ts` lists every value in design-foundations §1 (9 surfaces, 7 inks, 5 dark fills, 3 status families with hovers, clay, 8 match, 8 viz, 10 doc, 22 type roles, 13 radii, 14 shadows, 3 scrims, motion, z-index, ≈ 25 layout sizes), *when* `tokens.test.ts` parses `theme.css` and `root.css`, *then* every value is exactly equal.
- *Given* a probe file using `bg-red-500 text-sm shadow-lg font-bold rounded-lg`, *when* Tailwind compiles, *then* it emits no rules; `bg-green-tint text-body shadow-e2 rounded-pane` emit exactly the token values (namespaces reset with `initial`).

**A2. As Hannah Leclerc, I want secondary text I can read so that the product passes WCAG 2.2 AA (DEC-11).**
- *Given* the AA ladder (ink-2 text .70, ink-3 text .66, match text `#7E4590`, focus outline `2px solid rgba(43,31,23,.55)`), *when* axe runs on `/components/**` without `?contrast=reference`, *then* there are 0 serious or critical findings, and SPEC-016 AC-10 is not weakened.
- *Given* `?contrast=reference` in a gallery build, *when* the parity harness renders, *then* `<html data-contrast="reference">` restores the handoff ladder exactly; production builds ignore the parameter.

**A3. As N, I want the stack to refuse off-system styling so that drift fails CI, not review.**
- *Given* the new rules (palette regex that admits Accrued names, hex and `rgba(` ban in `packages/ui` outside `tokens/` and `brand/`, banned `font-semibold`/`text-lg`/`shadow-lg`, `toLocale*`/`Intl`/`toFixed` outside `format.ts`, `Date.now()` outside `clock.tsx`, the L1 brand strings), *when* a screen uses any of them, *then* ESLint fails; *and* `bg-green-tint` and `text-red-ink` pass. The independent cases (F-05-T08) are written in AY's session, not N's.
- *Given* a production build, *when* the compiled-CSS check scans `dist/*/assets/*.css`, *then* any 600/700 weight outside `[data-doc]` or any colour literal not in `tokens.ts` fails stage 1.

**A4. As Claire Feld on a strict network, I want fonts to load from the firm's own host.**
- *Given* Fontsource Geist and Geist Mono are preloaded and Arimo and Gelasio load only in document chunks, *when* any page loads, *then* no request goes to `fonts.googleapis.com` or `fonts.gstatic.com`, `document.fonts.check('500 13px Geist')` is true, and the `abacus-csp` meta in `apps/web/vite.config.ts` is unchanged.

### B. Numbers, status words, icons and the clock (S1)

**B1. As Margaret Okonkwo, I want every number formatted by one rule set so that two screens never disagree.**
- *Given* API money as decimal strings, *when* `amount(v, 'money')` runs, *then* parsing is exact through scaled `bigint` (15+ digits), negatives render in parentheses in `#B13327`, zero renders "—" in ink-4 unless `explicit`, halves round away from zero (`-2.5 → (3)`), and percent drops a trailing ".0".
- *Given* `now = 2026-09-14T09:24:00-05:00` and `tz = America/Chicago`, *when* the ≥ 60 golden cases run (F-05-T11, written by N), *then* `"-0.004" → —`, `"0.005" → $0.01`, `"-1234567.885" → ($1,234,567.89)`, the Nov 1 DST change and "Yesterday" across midnight all pass.

## 6. Accrued Agent

**None.** F-05 makes no model calls, registers no prompts, tools or agents, and has no gates of its own, so it has no eval suites or thresholds. It supplies the presentation guardrails every agent surface must use:

- `AgentText` stays the only renderer for agent strings (ADR-065); no markdown or HTML renderer is allowed (lint).
- `data-match` and citation markers derive from typed locators supplied by the backend, never from model text (ADR-066, INV-2).
- `HumanAction` and `formatActor` make "the agent never decides" and "X via Agent" structural (INV-1, INV-5); the toast Undo never commits or reverses a human gate on its own (DEC-24).
- Agent-filled values stay ink-2 with the atom glyph until a named person adopts them (C-31).
