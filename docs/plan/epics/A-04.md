# A-04 · Audit planning & risk (G4)

> Epic specification and task backlog, written Sunday 2026-10-18 for Sprint 0 (Mon 2026-10-19). Chapter 01 is the plan of record for order, dates, owners and scope; chapter 09 is the register of record for `DEC-nn`, `DF-nn` and ADR `P-nn` IDs. **AY** = ayushkbhatia, **N** = notanaskhan. The machine-readable backlog is `sections/epics/A-04.tasks.csv`; section 9 mirrors it row for row.
>
> **Short version.** A-04 gives the engagement partner gate **G4 "Planned"** on Accrued: a materiality decision computed in code and decided only by the EP, a SAS 145 risk register whose significant risks and rebuttals only the EP approves, the narrative and program workpapers with every value cited to the firm's methodology and the source page, internal control with a preliminary deficiency list, and the AU-C 402 service-organization evaluation. Six screens (AUD-04, AUD-05, AUD-07, AUD-08, AUD-09, AUD-10), a new amber `workpapers` module that A-05 and every later workpaper epic build on, the planning tables in `assurance`, and two agent capabilities (`workpapers.section_drafter`, `decisions.recommender`) that draft and recommend and never decide.
>
> It is built in S22–S28 (Aug 23 – Nov 26, 2027) for **December 2027 year-end planning** at the design-partner firms. S22–S25 sit inside the Sep 1 – Oct 20 busy-season window for firms live on EBP work, so A-04 merges dark and flips per firm from **Tue Oct 26, 2027**. The engagement run (P-10, S29–S38) and the run dock (P-09, S31–S34) come later: A-04's agent work runs as per-section draft runs on today's runtime and is dispatched by the engagement run when that lands.
