### 3.1 Business clock (server and browser) — P-37, DEC-27

**F-04.1 Demo instant on synthetic tenants.** As Hannah Leclerc on the staging demo tenant, I see the firm at its demo instant.
- *Given* Brightwater Hale has `firms.synthetic = true` and a `firm_demo_clocks` row (mode `offset`, anchor Mon 14 Sep 2026 09:24 CDT), *when* Hannah opens AUD-02 seventeen minutes after the reset, *then* the cockpit shows the AUD-02a running state at **9:41 AM** and every relative date is computed from `kernel.clock.now()`.
- *Given* the snapshot is E0, *when* AUD-03 renders Northwind requests due Sep 18, *then* no row shows "Overdue". *Given* snapshot `2026-09-21`, *then* those rows show AUD-03g's "Overdue" chips.

**F-04.2 Fail closed in production.**
- *Given* `environment = production`, *when* the API, worker or migration job starts with `ABACUS_DEMO_CLOCK` set, *then* startup fails with `ClockMisconfigured`.
- *When* any production tenant has a `firm_demo_clocks` row, *then* the tenant clock provider is never consulted and `abacus_now()` returns `clock_timestamp()`.

**F-04.3 Real tenants are immune at the database.** *Given* a staging tenant with `firms.synthetic = false`, *when* a transaction sets `app.now`, *then* `abacus_now()` ignores it. The check reads `firms.synthetic`, which only the owner role can write (migration 0038), so the app role cannot spoof it.

**F-04.4 Security time never shifts.** *Given* any demo clock, *when* code computes any of the following, *then* it calls `kernel.clock.system_now()` and the demo clock cannot shorten or extend it:
- MFA recency (`identity/authz` `mfa_recent`);
- OAuth state TTL (`connections/connect.py`);
- the Object Lock retain-until date (`evidence/storage.py`);
- USD budget windows (`ai_gateway/budgets.py`);
- provider-terms and route-parity dates;
- token expiry.

**F-04.5 Audit truth and business time.** *Given* any state change through the unit of work, *then* `audit_events.occurred_at` is the database system time (`clock_timestamp()`, unchanged) and `effective_at` is the business time (`abacus_now()`). The app role has no INSERT privilege on `effective_at`, so only the default writes it. Activity views read `effective_at` (INV-5 grammar unchanged).

**F-04.6 Temporal determinism.** *Given* workflow code, *then* it keeps `workflow.now()`. Activities resolve business time through `kernel.clock` with the tenant passed in. Existing replay tests in `backend/tests/workflows/` pass unchanged (ADR-090).

**F-04.7 Browser clock.** *Given* a screen in fixture mode, *then* `useNow()` resolves in this order:
1. the scenario's `clock`;
2. `?clock=` (dev, fixture and preview builds only);
3. `server_now` from `/v1/me` as an offset;
4. `Date.now()`.

*Given* the snapshot `2026-11-09`, *then* `format.ts` renders CST (UTC−6). ESLint fails `Date.now()` or an argument-less `new Date()` in `screens/**`, `domain/**` and `packages/ui/src/**` outside `clock.tsx`.

### 4.2 `kernel.clock` API (P-37)

```python
# backend/src/abacus/kernel/clock.py  (new, red, protected once merged)
def now(tenant: TenantContext | None = None) -> datetime      # business time; demo-aware
def today(tenant: TenantContext | None = None, zone: str | None = None) -> date
def system_now() -> datetime                                   # always real; security, TTLs, retention, budgets
@contextmanager
def frozen(at: datetime) -> Iterator[None]                     # tests and loader replay (contextvar)
def register_tenant_clock(provider: TenantClockProvider) -> None   # identity registers at startup
class ClockMisconfigured(RuntimeError): ...
```

- **Resolution:** the `frozen` contextvar, then the tenant provider (only when `settings().environment in {"local","test","staging"}`), then real time.
- **Provider cache:** per tenant, keyed `(synthetic, mode, anchor_at, anchored_real_at)`, TTL 60 s. For non-synthetic tenants it returns `None` without a query after the first read.
- **Offset mode:** `now = anchor_at + (system_now() − anchored_real_at)`.
- **Frozen mode:** allowed on staging only while the loader holds the tenant's load lock; in local and test, any time.
- **Compute engines never import `kernel.clock`.** The date is passed in (ch. 03 §10.1). The import-linter contract `compute → kernel.numeric, kernel.calendar` is unchanged.

### 4.3 Tables and migrations

One reversible migration, `00NN_business_clock` (red, N). The number is claimed at PR time after F-03's `0056–0066`, with `[mig 00NN]` in the PR title, under DEC-06 / P-38.

4. **`firm_demo_clocks`** (owner `identity`; `tenant_table()`; registered in identity's TABLE_OWNERS section under P-39):
