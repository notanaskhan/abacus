Invariants used below: **INV-1** the agent never decides (no approve, sign, confirm, resolve, send, export or request-approval on any agent path; matrix `agent: deny` plus human-only DB CHECKs); **INV-2** every citation shown is verified (ADR-066, ADR P-48); **INV-3** walls hold (walled records answer 404 and are never counted); **INV-4** portal scopes are isolated (no workspace data, draft K-1 or internal note reaches a portal principal); **INV-5** attribution is correct ("‹Person› via Agent" for agent work, never "Accrued Agent" as an approver).
