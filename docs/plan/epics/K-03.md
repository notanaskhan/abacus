## 1. Goal and user-visible outcome

**Goal.** Give Brightwater Hale a configurable engine for work that has no designed screen, without ever touching designed workpapers (D3 hybrid: AUD-04, AUD-09, TXP-11, CLS-04 and the rest are never converted). Concretely: (1) **templates v2** — a template version bundles a methodology version (program and steps, from K-01) with sheet definitions, forms, the request list, trigger defaults, report templates, skill pins and scoping rules; it is drafted invisibly, previewed against real engagements, published once by the QM owner, rolled out with a reason for every hold, and applied in place by each engagement's manager through a resumable Temporal workflow that **never touches signed-off work** (supersedes SPEC-008's pin-once); (2) **Sheets** — typed grids with 11 column types, rows from approved samples, record-value writes, row sign-offs that adopt suggestions and lock on reviewer sign-off, saved views and code-evaluated scoping rules; (3) **agent columns** — a firm-written instruction that @-references same-row columns and evidence, previewed on three real rows with a cost estimate before any run, producing **cited suggestions only**, which a named person adopts by signing the row off.
