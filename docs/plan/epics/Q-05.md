- *When* the batch completes, *then* tiles read 0 awaiting and 0 eligible, the history reads "Last destruction Sep 14, 2026 · certificate DC-2026-Q3", a toast confirms, both approvals are in ADM-07 (**FIL-02i**), and the certificate PDF (batch, scope, counts, approvers and times, hold re-check result, excluded count, fingerprints manifest hash, audit checkpoint root, and the statement that backups age out within 35 days) is stored in `records` in COMPLIANCE mode and re-renders byte-identically.
- *Given* a destroyed document, *then* any read answers 410 `destroyed` with "Destroyed under DC-2026-Q3"; FIL-01 shows the tombstone.
- *Given* "Export list (CSV)", *then* only the two approver roles may download it, with fresh MFA, as an audited export (`destruction_list.exported`, DEC-60).

### 3.13 Invariants across the epic

- **INV-1 the agent never decides:** no consultation conclusion, difference resolution, finding evaluation, inspection plan, evaluation conclusion, post-issuance decision, reissue, addition approval, hold, policy, approval or destruction has `actor_kind = 'agent'` (matrix deny, DB human-only CHECKs, I-AGENT-NEVER regenerated by T02, static DECISION-001 and ARCHIVE-001 rules).
- **INV-2 citations verified:** the PI-01 comparison values and the agent's analysis cite verified regions of both certifications; the shared severity proposal on AUD-28 keeps its verified citations.
- **INV-3 walls:** consultations, holds, inspection rows, candidates, findings linked to engagements and destruction batch lists are wall-filtered with no hidden counts; an inspection grant never overrides a wall.
- **INV-4 portal isolation:** nothing in Q-05 is client-facing; no route is reachable by a portal principal (generated deny tests).
- **INV-5 attribution:** every state change writes one `audit_events` row with the right actor grammar: the nightly finding as the system actor; run #4511 as "Hannah Leclerc via Agent".
- **Archive integrity:** writes to a locked work item happen only under `post_issuance`, `archive_addition` or `destruction_tombstone`, from the allowlisted functions only.
- **Retention:** no evidence object is deleted before its policy expiry and its S3 retain-until, or while any hold covers it (I-RETENTION-FLOOR, I-HOLD).
