**Lessons.**
- The local `main` was stale: always diff against the sprint's base (`47a3b87fe`), never `main`.
- BOUND-002: a cross-module slot (the ledger sync scope, connection coverage) belongs in the kernel.
- Column grants: the app inserts a row's start and updates its result; ON CONFLICT DO UPDATE
  needs the insert grant on every listed column.
- Postgres evaluates a column's default before a later column's `clock_timestamp()`: compare a
  CHECK across columns on one clock (`now()` for the later one).
- A `FORCE` RLS table hides rows from its own definer: fan out firm by firm instead.
